# Map Method для Windows

Установщик `Map-Method-Setup.exe` создаёт отдельное приложение для Windows x64,
ярлык на рабочем столе и пункт в меню «Пуск». Установка доступна для текущего
пользователя без обязательных прав администратора.

Приложение использует собственный Electron, а не установленный браузер.
Интерфейс загружается с `https://www.mapmethod.ru/`, поэтому обновления сайта
доступны без повторной установки. Первый запуск требует интернета. После
успешной загрузки применяется существующий механизм кеширования сайта.
Офлайн-доступ зависит от сохранённых на устройстве данных и сессии аккаунта.

Войти в аккаунт в приложении нужно отдельно: cookies браузера не импортируются.
Карты аккаунта синхронизируются через тот же Supabase. Гостевые карты браузера
можно перенести существующей резервной копией. Удаление приложения сохраняет
его локальные данные.

Команды из корня проекта:

- `npm run desktop:start` — запуск приложения.
- `npm run desktop:build` — сборка установщика в `release/`.
- `node --test tests/desktop.test.mjs` — быстрые проверки ограничений переходов
  и настроек установщика.

Версия оболочки задаётся в `desktop/electron-builder.cjs`.
GitHub Actions собирает установщик и публикует его в Releases при изменении
файлов приложения или зависимостей. Для каждого нового выпуска нужно увеличить
версию оболочки. Releases использует теги `v<версия>` и публикует установщик,
его blockmap и `latest.yml`. `electron-updater` проверяет обновления при запуске
и каждые 4 часа, скачивает их в фоне и предлагает перезапуск. Перед установкой
текущая карта сохраняется в локальную очередь. Неупакованный запуск не обновляется.
Установщик пока не имеет цифровой подписи издателя.
